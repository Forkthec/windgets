# prototipos

Prototipos visuales de Windgets (WG-MK-01, versión 2, 8-oct-2026), hechos en Claude Design y revisados por Juan
Diego Gómez Garcés (Gerente). Regla de uso: `docs/interfaz.md`, «Colores y tipografía», «Prototipos visuales».
Los mockups mandan en la distribución y el aspecto; las historias de usuario, en los textos, los campos, los
mensajes y el comportamiento.
